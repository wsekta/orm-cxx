Detailed Description

A session-bound, stable exchange buffer for one Binary16 parameter or result. The buffer and its indicator must outlive the statement using them. SQLite results additionally require typeof(value) from the same row, because SOCI's blob exchange converts other storage classes before returning the bytes.

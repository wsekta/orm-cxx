Detailed Description

A 128-bit UUID in canonical byte order, independent of a database backend.

Default construction produces the nil UUID. Parsing accepts exactly the 8-4-4-4-12 hexadecimal format, with either case; formatting uses lowercase. Every 128-bit pattern is representable. Byte ordering in C++ does not promise the same order as a database's native UUID comparisons.

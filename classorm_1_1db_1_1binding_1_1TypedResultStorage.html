Detailed Description

Owns stable per-column buffers for explicit SOCI exchanges. New scalar types always use into(string, indicator), bypassing dynamic row/date conversion. Its row view retains the existing hydration and numeric checks without allocating unbound soci::values holders, whose lifetime SOCI cannot manage.
